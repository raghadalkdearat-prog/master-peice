# Wakeel — Master-Admin-Cycle

افتح master-admin-dash/dashboard.html باستخدام VS Code Live Server.

## النطاق
11 صفحة: لوحة التحكم، المستخدمون، المعاملات، تفاصيل المعاملة، المدفوعات والمستحقات، الدعم والشكاوى، التقييمات، الإشعارات، فئات الخدمات، الإعدادات والصلاحيات، سجل الإجراءات.

## الهوية المشتركة
تستخدم الصفحات CSS لوحة العميل وshared.css وCSS دورة الوكيل مباشرة.
يحمّل admin-shell.js نفس nav.html وfooter.html من Master-Client-Cycle/shared، ويكيّف روابط نسخة DOM الخاصة بالإدارة.
لا تعدّل ملفات العميل أو الوكيل.
admin-shell.css يمتد من التنسيقات الموجودة ويحافظ على RTL والموبايل وتقليل الحركة.

## الاستقلال
المفتاح الوحيد: wakeel_admin_demo_v1.
لا تقرأ الإدارة مفاتيح العميل أو الوكيل ولا تكتب فيها.
روابط مساحات العميل والوكيل للتنقل فقط.
لإعادة التجربة الافتراضية، احذف مفتاح الإدارة وحده من Local Storage في أدوات المطور.

## الصلاحيات التجريبية
الإدارة الكاملة، الدعم، المراجعة، المالية.
صفحة الإعدادات تتيح تبديل حساب العرض محليًا لتجربة اختلاف الصلاحيات.
الصلاحيات تتحقق في عرض الصفحات وفي تنفيذ الأوامر. تخزين المتصفح ليس حماية أمنية فعلية.
يحتاج التطبيق الحقيقي مصادقة وصلاحيات على الخادم، وسجلًا مركزيًا محميًا.
صلاحيات دور الإدارة الكاملة ثابتة؛ لا يمكن تغيير دور الحساب الحالي أو إزالة آخر مسؤول كامل نشط.

## قواعد الإجراءات
- الإجراءات المؤثرة تحتاج سببًا وتسجل صاحبها ووقتها والقيم قبلها وبعدها.
- لا يُلغى طلب نشط عند تعليق مستخدمه تلقائيًا.
- اختيار العرض من العميل؛ الإدارة لا تختار عرضًا بديلًا.
- المعاملات المكتملة أو الملغاة نهائية؛ مراجعتها اللاحقة تتم عبر الدعم.
- تعليق أو إلغاء معاملة ذات مبلغ محجوز يعلق التسوية، ولا ينفذ استردادًا.
- التسوية تحتاج معاملة مكتملة ومبلغًا محجوزًا دون تعليق أو شكوى مفتوحة، ووكيلًا نشطًا معتمدًا في بيانات التجربة.
- الاسترداد يحتاج مبلغًا محجوزًا ومعاملة ملغاة أو موقوفة.
- طلب تصحيح المبلغ سجل منفصل بانتظار المراجعة؛ لا يغير المبلغ الأصلي أو العرض المقبول.
- مراجعة المحادثة تتطلب صلاحية وتذكرة مرتبطة وسببًا؛ محتوى الرسائل لا ينسخ إلى سجل الإجراءات.
- إخفاء التقييم يحافظ على النص والنجوم الأصليين.
- تعطيل الفئات يحافظ على مراجع المعاملات وتصنيفها الأصلي.
- لا توجد مصادقة أو حركة أموال أو إرسال إشعارات أو رفع ملفات فعلي.

## ملفات مشتركة
master-admin-shared/admin-data.js: البيانات، الصلاحيات، الأوامر وقواعدها، الحفظ والسجل.
master-admin-shared/admin-shell.js: المكونات المشتركة والنوافذ والفلاتر والتحقق من الوصول.
master-admin-shared/admin-shell.css: التنسيقات الإضافية.
