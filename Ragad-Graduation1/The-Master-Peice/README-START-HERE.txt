Wakeel | Client cycle integration (local front-end prototype)

Start: open master-landing-page/landing.html with VS Code Live Server.
Navigation: Navbar/sidebar links point to the existing actual nested HTML pages.
Create Request: draft and publish demo entries are stored in localStorage and displayed in My Requests. Details for these entries are also displayed in Request Details. No server is contacted.
Other prototype features (payments, offers, support, reviews, authentication) do not constitute real transactions or actual secure login.
Sign-in/Register UI are included but no real authentication backend exists.
Some legal/forgot-password destinations are marked unavailable because no corresponding pages were supplied.

Files remain organized in their original folders; the shared client script is Master-Client-Cycle/wakeel-client-links.js.
