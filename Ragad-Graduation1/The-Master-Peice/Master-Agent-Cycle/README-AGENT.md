# Wakeel — Master-Agent-Cycle
شغّل master-agent-dash/dashboard.html عبر Live Server من جذر المشروع، أو استخدم حساب الوكيل في Demo Login.

## الصفحات
لوحة التحكم، الطلبات المتاحة، معاملاتي، تفاصيل المعاملة، المدفوعات والمستحقات، الإشعارات، الملف الشخصي، التقييمات، المساعدة والدعم.

## دورة المعاملة
تُشارك المعاملات والعروض والدفع والتقييمات وبيانات التواصل عبر wakeel_workflow_v2. يُستورد wakeel_agent_demo_v1 السابق دون حذف المفتاح الأصلي. العرض ينتظر قبول العميل ثم الدفع؛ النجاح يتيح التنفيذ، والإتمام يحدّث المستحق المرتبط.

ملاحظة التنفيذ تظهر للعميل بجانب «قيد التنفيذ»، وتدخل محادثة المعاملة مع مرجع يمكن للعميل الرد عليه. المحادثة متاحة للوكيل الذي اختير عرضه ولصاحب الطلب، إلى جانب واتساب والاتصال. تبقى الملاحظات السابقة محفوظة ويستمر عرضها بعد الإتمام.

تذاكر الوكيل تُشارك مع مدير المنصة في supportTickets، مع محادثة وردود وحالات متابعة. تُرحّل agentTickets القديمة دون حذفها. رد المدير يصل إلى إشعارات الوكيل ويفتح التذكرة الصحيحة.

navbar وfooter وتنسيقات العميل المشتركة محفوظة، مع بروفايل دائري وبيانات اتصال مشتركة. جميع وظائف الجلسة والرسائل والدفع في المرحلة الحالية محلية؛ المشاركة بين أجهزة أو تحصيل الأموال أو المصادقة الفعلية تحتاج خادمًا.
